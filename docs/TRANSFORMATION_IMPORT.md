# Transformation Portfolio import

Open `index.html`, select **Transformation Overview**, and choose a local `.xlsx` file. The workbook must contain sheets named `Planned High Level Streams` and `Detailed Plan`. Review the preview, including changes, removals and data quality warnings, before selecting **Confirm and apply import**. The browser makes no upload or external API call. The workbook file itself is not saved; its mapped values and source row references are saved in IndexedDB and included in JSON backup.

The high-level sheet uses `Location`, `Workstream`, `TA`, `Category`, `Detail`, `Start`, `End`, `Dependency` and optional month columns such as `Jan 2027`. The detailed sheet uses `Programme Area`, `Phase`, `Task`, `Source Schedule`, `Resources`, `Source Category`, `Start`, `End`, `Planning Status`, `Source Line` and `Notes`. Header rows may follow a title. All source cell display values are preserved. Parsed dates are additional fields. Numeric Excel dates, ISO dates, South African `dd/mm/yyyy` and `dd/mm/yy`, and `dd Mon yyyy` are supported; ambiguous slash dates are read day-first. Month markers are kept separately and conflicts with Start/End are flagged without correction.

Records are matched on source identity: high-level `Location + Workstream + TA` and detailed `Source Line` when present, otherwise `Programme Area + Phase + Task + Source Schedule`. Duplicate identity rows receive an occurrence number and a quality warning. Changing an identity field can therefore appear as one removed and one new item. Re-importing an unchanged workbook does not duplicate streams or activities. Removed source items stay in local history with their architect mappings.

Use **Architecture detail** to set a gate and link existing domains, sites, branches, topology components, branch patterns, decisions, dependencies and sources. HLD, LLD and validation requirements may be entered as references. An exact Category match appears as a source domain suggestion (`S`) in the impact matrix; an architect mapping is shown separately (`●`). Detailed activities link to high-level streams only when the architect selects a stream. Source Planning Status never updates an Architecture Gate. A stream with mapped topology components can highlight them on the existing topology.

The included SheetJS browser bundle is `@e965/xlsx` 0.20.3 (Apache 2.0); its license is in `vendor/XLSX-LICENSE.txt`. The repository contains only synthetic workbook rows generated in tests and demonstration data. The actual `OM Plan - streams.xlsx` was not available in this task, so verify its real header labels and date formats with a local preview before applying.
