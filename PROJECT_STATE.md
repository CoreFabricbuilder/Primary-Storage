# Project state

The cockpit is a zero-install, direct-file browser application with IndexedDB and JSON backup. The browser CSP blocks outbound connections. Optional vendor collectors run outside the browser.

The merged Current Deployment Report import adds schema 8, sourced pre-SD-WAN Current/Observed branch snapshots and a reviewed CSV import. The overview now summarizes imported branch coverage, access types, regions, reported switch/AP counts and source issues. Its grouping lines are explicitly not network links. Transition/Future views show target-pattern coverage and direct the architect to define intent; they do not treat imported values as validated. It groups gaps by architecture area, retains Current source/classification, and shows related decisions and dependencies. No scenario changes assigned patterns, validation or As-Built Baselines.
